## Overview

The cyclic equivariant encoding constructs quantum feature maps that are exactly equivariant under the cyclic group $\mathbb{Z}_n$, the group of discrete rotations by $2\pi k / n$ for $k = 0, 1, \ldots, n-1$. This encoding is suited for data with discrete translational or rotational symmetry, such as signals on a periodic lattice or features with a natural cyclic ordering.

## Cyclic Group and Qubit Permutation

The cyclic group $\mathbb{Z}_n$ is generated by a single element -- the cyclic shift $\sigma$ that maps index $i$ to $i + 1 \pmod{n}$. On an $n$-qubit register, this shift is represented by a permutation unitary:

$$P_\sigma |q_1, q_2, \ldots, q_n\rangle = |q_n, q_1, q_2, \ldots, q_{n-1}\rangle$$

The encoding is **equivariant** if applying a cyclic shift to the input features produces the same effect as applying $P_\sigma$ to the quantum state:

$$U(\sigma \cdot \mathbf{x}) = P_\sigma\, U(\mathbf{x})\, P_\sigma^\dagger$$

This ensures that the feature map treats all cyclic permutations of the input equivalently, up to a corresponding permutation of the quantum state.

## Ring Topology and $R_{ZZ}$ Gates

The circuit enforces cyclic symmetry through a **ring connectivity** pattern. Each qubit $i$ is entangled with its neighbor $i + 1 \pmod{n}$ via an $R_{ZZ}$ gate:

$$R_{ZZ}(\alpha) = \exp\!\bigl(-i \frac{\alpha}{2} Z_i Z_{i+1}\bigr)$$

Crucially, all $R_{ZZ}$ gates on the ring share the **same coupling parameter** $\alpha$, which may depend on data features. This parameter sharing is what enforces translational invariance: the entangling layer looks identical from every qubit's perspective.

A single entangling layer applies:

$$U_{\text{ent}}(\alpha) = \prod_{i=0}^{n-1} R_{ZZ}(\alpha)\big|_{i,\, (i+1) \bmod n}$$

## Translational Invariance

Translational invariance on the ring means that the circuit commutes with cyclic shifts: $[U_{\text{ent}}, P_\sigma] = 0$. This holds because every edge $(i, i+1 \bmod n)$ in the ring is mapped to another edge $(i+1, i+2 \bmod n)$ under the cyclic shift, and all edges carry the same gate parameter.

For the data-encoding layer, translational invariance requires that feature $x_i$ is encoded on qubit $i$ with the same gate type and functional form for all $i$:

$$S(\mathbf{x}) = \bigotimes_{i=0}^{n-1} R_Y(f(x_i))$$

where $f$ is a fixed nonlinear function applied uniformly. When the input is cyclically shifted as $\sigma \cdot \mathbf{x} = (x_n, x_1, \ldots, x_{n-1})$, the encoding layer satisfies $S(\sigma \cdot \mathbf{x}) = P_\sigma S(\mathbf{x}) P_\sigma^\dagger$.

## Coupling Strength Parameter

The coupling strength $\alpha$ in the $R_{ZZ}$ gates controls the degree of entanglement between neighboring qubits. Two regimes are notable:

- **Weak coupling** ($\alpha \ll 1$): Qubits are nearly independent, and the encoding approximates a product-state feature map. Correlations between neighboring features are weakly captured.
- **Strong coupling** ($\alpha \approx \pi/2$): Maximum entanglement between neighbors. The quantum state becomes highly correlated, and the feature map captures strong inter-feature dependencies.

The coupling strength can be fixed as a hyperparameter or made data-dependent, e.g., $\alpha = g(\mathbf{x})$ for some symmetric function $g$. Data-dependent coupling enriches the feature map but must preserve cyclic symmetry by depending on $\mathbf{x}$ only through $\mathbb{Z}_n$-invariant functions.

## Multi-Layer Construction

A complete cyclic equivariant encoding stacks $L$ layers, each consisting of a data-encoding sublayer and an entangling sublayer:

$$U(\mathbf{x}) = \prod_{l=1}^{L} U_{\text{ent}}(\alpha_l)\, S(\mathbf{x})$$

Each layer $l$ may have its own coupling strength $\alpha_l$, but the ring topology and parameter sharing within each layer are preserved. Increasing $L$ allows the circuit to express higher-order correlations while maintaining exact $\mathbb{Z}_n$ equivariance at every layer.

## Practical Guidance

Cyclic equivariant encoding is appropriate when the feature indexing has a natural periodic structure -- for example, sensor readings arranged in a circle, hourly time series data, or molecular descriptors along a ring-shaped molecule. The number of qubits should match the number of features (or a divisor thereof). Start with $L = 2$ layers and moderate coupling $\alpha \approx \pi/4$, tuning both based on validation performance. If the data has approximate but not exact cyclic symmetry, consider using a symmetry-inspired encoding instead, which offers more flexibility.
